# Contributing to AttendX Pro

Thank you for your interest in contributing to AttendX Pro! This project is an open-source platform designed to replace manual spreadsheet attendance tracking with modern, cloud-synchronized attendance and payroll workflows.

---

## 🛠️ Code of Conduct
We are committed to providing a friendly, safe, and welcoming environment for all contributors. Please be respectful and constructive in all discussions.

---

## 🚀 Getting Started

1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/attendx-pro.git
   cd attendx-pro
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🧪 Testing & Code Quality

Before opening a pull request, ensure your code passes TypeScript type checking and builds successfully:

```bash
# Typecheck
npm run lint

# Build frontend & backend
npm run build
```

---

## 📋 Pull Request Guidelines

1. Create a feature branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Keep commits concise and meaningful.
3. Verify mobile responsiveness and tabular figure alignments.
4. Ensure no secrets, tokens, or hardcoded sensitive data are included.
5. Push to your fork and submit a Pull Request to `ccheran10/attendx-pro:main`.
